7. Run locally instead (same engine, Python package)




Then on your computer (Python 3.10+), in the folder containing kotha_job.json:


python -m venv kotha-env
# Windows PowerShell:  kotha-env\Scripts\Activate.ps1
# macOS / Linux:       source kotha-env/bin/activate
pip install kotha-0.2.0rc1-py3-none-any.whl
kotha validate kotha_job.json
kotha run kotha_job.json --output kotha_result.json --report kotha_report.html
